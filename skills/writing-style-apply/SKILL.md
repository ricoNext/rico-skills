# 作者行文风格（应用与套用）

## 适用范围

- **本 skill 只负责**：按已有作者档案**改写**给定内容，或**生成**文章/段落。
- **不负责**：从样例或网页归纳风格、创建/更新档案（请用 **writing-style-learn**）。
- **作者**：可由用户指定；未指定时一律视为 **`default`（默认作者）**。
- **运行时数据位置**：只读 `~/.rico-skills/author-writing-style/profiles/<author_slug>.md`；**禁止**向 skill 安装目录写入个人档案。

## 作者档案目录（固定路径）

- **目录**：`~/.rico-skills/author-writing-style/profiles/`（将 `~` 展开为用户主目录的绝对路径）。
- **某一作者档案文件**：`~/.rico-skills/author-writing-style/profiles/<author_slug>.md`

不在此路径之外查找作者风格档案。仓库内 `skills/writing-style-learn/profiles/`（若有）**仅可作只读参考**，不得作为运行时写入目标。

## 作者标识（author_slug）

1. 若用户提供了可用于文件名的英文标识（如 `rico-blog`），直接使用：转小写，将空格改为 `-`，仅保留 `[a-z0-9-]`，连续连字符合并为一条。
2. 若用户只给中文名或其它 Unicode 名：在已有档案中按 `author_display_name` 匹配；匹配不到时向用户确认 slug，或提示先用 **writing-style-learn** 建档。
3. **`default`**：用户未说明作者时，`author_slug` 固定为 `default`。

## 按作者行文习惯改写或生成

**触发**：用户要求按某作者（或默认作者）的既有习惯**改写**给定内容，或**生成**文章/段落。

**步骤**：

1. **解析作者**：未指定则用 `default`。
2. **加载档案**：读取 `~/.rico-skills/author-writing-style/profiles/<author_slug>.md`（`~` 已展开）。若不存在或关键段落大量为「待归纳」且几乎无可用规则：如实告知需先执行 **writing-style-learn** 提供样例；若用户坚持生成，仅基于有限信息给出保守输出，并声明依据不足。
3. **执行创作**：
   - **改写**：在保持用户给定事实与意图的前提下，调整句式、节奏、衔接与版式以贴合档案；不捏造事实。
   - **生成**：主题与要点来自用户指令；风格严格对齐档案；若用户要求字数、体裁、大纲，一并遵守。
4. **输出**：直接给出成品正文；必要时在正文后可附极短的「相对档案的对应说明」（用户不需要则可省略）。

## 质量与安全

- **隐私**：不在回复中复述用户样例里的敏感信息。
- **版权**：生成与改写不刻意复刻第三方作品的独特表达；用户要求模仿特定真人/名家时，同样只保留结构层面习惯。
- **冲突**：用户指令与档案冲突时，以用户**本次明确指令**为准。
- **不联网学风格**：本 skill **不**主动抓取网页建档；若用户希望按「某网页当前文风」改写但未建档，应先走 **writing-style-learn**（粘贴文本或 URL）再建档，再回来套用。

## 示例（极简）

- 读取 `~/.rico-skills/author-writing-style/profiles/default.md` 后输出改写稿。
- 「按 `ruan-yifeng` 档案写一段说明」→ 读取对应档案后生成。
